# Forcepoint

> Forcepoint is a data security company that protects sensitive data everywhere it moves — across AI applications and agents, cloud, web, email, endpoint and the network. Its AI-native platform discovers and classifies data, adapts enforcement to user risk in real time, and secures AI interactions from user prompts to autonomous agents.

For more than 20 years Forcepoint has protected sensitive data for defense, intelligence, finance, healthcare and global enterprises. It has 12,000+ customers in 150 countries, including 485 of the Forbes Global 2000.

Its portfolio has three areas:

- **AI Security** governs AI use across sanctioned apps, shadow AI and AI agents.
- **Data Security Everywhere** covers DLP, DSPM, DDR, data classification, web, cloud and email security.
- **Network Security** covers next-generation firewall and secure SD-WAN.

## AI Security Products

- [Forcepoint AI Data Security](https://www.forcepoint.com/ai-data-security): Discovers, classifies and enforces data security at every AI interaction, from sanctioned applications and shadow AI to cloud- and endpoint-resident agents.

## Data Security Everywhere Products

- [Forcepoint DLP](https://www.forcepoint.com/product/dlp-data-loss-prevention): Data loss prevention for sensitive data in the cloud, web, email, network and endpoint, managed under a single policy with 2,000+ classifiers.
- [Forcepoint DSPM (Data Security Posture Management)](https://www.forcepoint.com/product/data-security-posture-management-dspm): Discovers, classifies and remediates sensitive data at rest, with AI-powered automation.
- [Forcepoint DDR (Data Detection and Response)](https://www.forcepoint.com/product/data-detection-response-ddr): Continuous monitoring to detect and stop data breaches.
- [Forcepoint Data Classification](https://www.forcepoint.com/product/forcepoint-data-classification): AI-powered classification that improves accuracy and efficiency in identifying sensitive data.
- [Risk-Adaptive Protection (RAP)](https://www.forcepoint.com/product/risk-adaptive-protection): Automates data security enforcement based on each user's real-time risk.
- [Forcepoint Web Security](https://www.forcepoint.com/product/secure-web-gateway-swg): Secure web gateway for safe browsing and file downloads.
- [Data Security for Cloud Apps (CASB)](https://www.forcepoint.com/product/casb-cloud-access-security-broker): Secures data in public cloud and SaaS applications.
- [DLP for Email](https://www.forcepoint.com/product/email-data-loss-prevention-dlp): Prevents data exfiltration in outbound email.
- [Forcepoint Email Security](https://www.forcepoint.com/product/email-security-software): Inbound threat protection that extends the native security of leading email platforms.
- [Remote Browser Isolation (RBI)](https://www.forcepoint.com/product/remote-browser-isolation): Renders risky websites in an isolated container so users can browse safely.
- [Advanced Malware Detection and Protection (AMDP)](https://www.forcepoint.com/product/advanced-malware-detection): Protection against advanced malware and zero-day exploits.

## Network Security Products

- [Forcepoint Next-Generation Firewall (NGFW)](https://www.forcepoint.com/product/ngfw-next-generation-firewall): Firewall with built-in SD-WAN and high security efficacy to defend the network edge.
- [Forcepoint Secure SD-WAN](https://www.forcepoint.com/product/secure-sd-wan): Connects and protects offices, branches and remote sites.

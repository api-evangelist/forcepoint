# Forcepoint

> Forcepoint is a data-first cybersecurity company providing Data Loss Prevention (DLP), Security Service Edge (SSE / SASE), Next-Generation Firewall (NGFW), and web/email/data security. It exposes several product REST APIs for policy management, provisioning, log export, and firewall automation, plus first-party Python, Ansible, and Terraform tooling.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface and catalog artifacts. Forcepoint does not publish a machine-readable OpenAPI; API contracts are documented as HTML on help.forcepoint.com.

## APIs
- [Forcepoint Data Security Cloud | SSE REST API](https://help.forcepoint.com/fpone/sse_admin/prod/guid-aad2ad06-3314-41db-adc5-58e0a8c81baa.html): Config, Log export, IP and SCIM 2.0 provisioning APIs for Forcepoint ONE / SSE; OAuth 2.0 bearer auth.
- [Forcepoint DLP REST API](https://help.forcepoint.com/dlp/90/restapi/index.html): Policy management over JSON/HTTP for Forcepoint Data Loss Prevention.
- [Forcepoint NGFW SMC API](https://help.forcepoint.com/ngfw/en-us/7.0.0/smc_api_ug/index.html): RESTful Security Management Center API (JSON/XML) for firewall/engine/policy automation.
- [Forcepoint Appliance REST API](https://help.forcepoint.com/docs/appliance/v85/appliance_api/index.html): Appliance management REST API.
- [Forcepoint Web Security Cloud API](https://help.forcepoint.com/websec/en-us/cloud/api/index.html): Cloud web security programmatic access.

## Auth
- [Setting up an OAuth token (SSE)](https://help.forcepoint.com/fpone/deploy/rhtml/guid-18f77855-8dc9-436a-9fba-179f06a81066.html): OAuth 2.0 bearer tokens; scopes configured under Settings > API Interface > OAuth.
- [How to Start Using SMC API](https://support.forcepoint.com/s/article/How-to-Start-Using-SMC-API): API-key auth via an SMC API Client element.
